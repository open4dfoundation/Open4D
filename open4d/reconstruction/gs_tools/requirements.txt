# Pip set for the open4d-gs environment: the union of what QUEEN and 3DGStream
# import, minus anything that has to be compiled per-machine.
#
# Install torch first, from the cu126 index:
#   pip install torch==2.7.0 torchvision==0.22.0 \
#     --index-url https://download.pytorch.org/whl/cu126
#
# Compiled extensions are not here and cannot be: the rasterizer, simple-knn, and
# tiny-cuda-nn are all built against one exact torch/CUDA pair by
# scripts/setup.sh. See README.md.

# backbone; that pin lives in requirements-midas.txt and runs in its own
# environment so depth-prior generation cannot constrain training.
